这个数据库是如何建立的

每个条目都来自我们审核并载入 XposedOrNot 的泄露事件，与免费邮箱检查和 API 使用的是同一份数据。我们记录泄露日期、泄露的记录数、行业、泄露的数据类型以及密码的存储方式。

绿色对勾表示我们已根据来源核实该泄露事件。标记为敏感的条目会列在这里，但不会出现在公开的邮箱搜索结果中，以免其中的当事人被二次曝光。

完整方法见我们的方法论页面，开发者也可以通过免费 API 获取同一份列表。

常见问题

XposedOrNot 数据泄露数据库是什么？

它是一份免费、可搜索的列表，收录了我们已载入的所有公开已知泄露事件，目前共 789 起。每个条目都显示泄露的记录数、行业、泄露日期、密码存储方式以及我们是否已核实。无需账户。

如何按行业或年份搜索泄露事件？

使用表格上方的行业、年份和密码风险筛选条件，或在搜索框中输入公司名称或域名。筛选条件可以组合使用，点击重置即可清除。

密码风险是什么意思？

它表示被泄露的网站如何存储密码。明文表示没有任何保护，易破解表示使用了 MD5 或 SHA1 等弱哈希，难破解表示使用了 bcrypt 等强哈希。未知表示我们无法从数据中判断。

泄露数据库是免费的吗？

是的。无需注册即可浏览、搜索和筛选。如果您希望把数据接入自己的工具，也可以通过我们的免费 API 获取同样的数据。

多久更新一次？

每当有新的泄露事件经过核实并载入时就会更新。页面顶部的“最后更新”一行显示最新添加的条目，每个条目都同时标注泄露日期和添加日期。
