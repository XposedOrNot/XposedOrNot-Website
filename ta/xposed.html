789 மீறல்கள் கண்டறியப்பட்டன
லோகோ மீறல் தொழில்துறை பதிவுகள் மீறல் தேதி கடவுச்சொல் அபாயம் நிலை நடவடிக்கை

இந்தத் தரவுத்தளம் எவ்வாறு உருவாக்கப்படுகிறது

ஒவ்வொரு பதிவும் நாங்கள் ஆய்வு செய்து XposedOrNot-இல் ஏற்றிய மீறலிலிருந்து வருகிறது. இலவச மின்னஞ்சல் சரிபார்ப்புக்கும் API-க்கும் பின்னால் இருப்பதும் இதே தரவுதான். மீறல் தேதி, வெளிப்பட்ட பதிவுகளின் எண்ணிக்கை, தொழில்துறை, கசிந்த தரவு வகைகள், கடவுச்சொற்கள் சேமிக்கப்பட்ட முறை ஆகியவற்றைப் பதிவு செய்கிறோம்.

பச்சை டிக் குறி என்பது மீறலை அதன் மூலத்துடன் ஒப்பிட்டுச் சரிபார்த்துள்ளோம் என்பதைக் குறிக்கும். உணர்திறன் வாய்ந்தவை எனக் குறிக்கப்பட்ட பதிவுகள் இங்கே பட்டியலிடப்படும், ஆனால் பொது மின்னஞ்சல் தேடல் முடிவுகளில் காட்டப்படாது. அவற்றில் உள்ளவர்கள் இரண்டாவது முறை வெளிப்படாமல் இருக்கவே இந்த ஏற்பாடு.

முழு முறையும் எங்கள் முறையியல் பக்கத்தில் உள்ளது, மேலும் டெவலப்பர்கள் இதே பட்டியலை இலவச API மூலம் பெறலாம்.

அடிக்கடி கேட்கப்படும் கேள்விகள்

XposedOrNot தரவு மீறல் தரவுத்தளம் என்றால் என்ன?

நாங்கள் ஏற்றிய, பொதுவில் அறியப்பட்ட ஒவ்வொரு மீறலின் இலவச, தேடக்கூடிய பட்டியல் இது, இதுவரை 789. ஒவ்வொரு பதிவும் வெளிப்பட்ட பதிவுகள், தொழில்துறை, மீறல் தேதி, கடவுச்சொற்கள் சேமிக்கப்பட்ட முறை, நாங்கள் அதைச் சரிபார்த்தோமா என்பதைக் காட்டுகிறது. கணக்கு தேவையில்லை.

தொழில்துறை அல்லது ஆண்டு வாரியாக மீறல்களை எவ்வாறு தேடுவது?

அட்டவணைக்கு மேலே உள்ள தொழில்துறை, ஆண்டு, கடவுச்சொல் அபாயம் வடிகட்டிகளைப் பயன்படுத்தவும், அல்லது தேடல் பெட்டியில் நிறுவனத்தின் பெயர் அல்லது டொமைனை உள்ளிடவும். வடிகட்டிகள் இணைந்து செயல்படும், மீட்டமை அவற்றை நீக்கும்.

கடவுச்சொல் அபாயம் என்றால் என்ன?

மீறப்பட்ட தளம் கடவுச்சொற்களை எவ்வாறு சேமித்தது என்பதை இது குறிக்கிறது. வெற்று உரை என்றால் எந்தப் பாதுகாப்பும் இல்லை, எளிதில் உடைக்கக்கூடியது என்றால் MD5 அல்லது SHA1 போன்ற பலவீனமான ஹாஷிங், கடினமாக உடைக்கக்கூடியது என்றால் bcrypt போன்ற வலுவான ஹாஷிங். தெரியாதது என்றால் தரவிலிருந்து அதை எங்களால் அறிய முடியவில்லை.

மீறல் தரவுத்தளம் இலவசமா?

ஆம். பதிவு செய்யாமலேயே உலாவவும், தேடவும், வடிகட்டவும். உங்கள் சொந்தக் கருவிகளில் பயன்படுத்த விரும்பினால் இதே தரவு எங்கள் இலவச API மூலமும் கிடைக்கும்.

இது எவ்வளவு அடிக்கடி புதுப்பிக்கப்படுகிறது?

புதிய மீறல் சரிபார்க்கப்பட்டு ஏற்றப்படும் ஒவ்வொரு முறையும். மேலே உள்ள "கடைசியாக புதுப்பிக்கப்பட்டது" வரி மிகப் புதிய சேர்க்கையைக் காட்டுகிறது, ஒவ்வொரு பதிவிலும் மீறல் தேதியும் நாங்கள் சேர்த்த தேதியும் இருக்கும்.
