このデータベースの作成方法

各エントリは、私たちが確認して XposedOrNot に読み込んだ侵害に基づいています。無料のメールチェックや API と同じデータです。侵害日、漏洩したレコード数、業種、漏洩したデータの種類、パスワードの保存方法を記録しています。

緑のチェックマークは、情報源に照らして侵害を検証済みであることを示します。機微とマークされたエントリはここに掲載されますが、公開のメール検索結果には表示されません。該当する方々が二重に晒されないようにするためです。

詳しい手法は方法論のページに掲載しています。開発者は無料 APIから同じリストを取得できます。

よくある質問

XposedOrNot のデータ侵害データベースとは何ですか？

私たちが読み込んだ、公に知られているすべての侵害を検索できる無料のリストで、現在787件です。各エントリには漏洩レコード数、業種、侵害日、パスワードの保存方法、検証済みかどうかが表示されます。アカウントは不要です。

業種や年で侵害を検索するにはどうすればよいですか？

表の上にある業種、年、パスワードのリスクのフィルターを使うか、検索ボックスに企業名やドメインを入力してください。フィルターは組み合わせて使え、リセットで解除できます。

パスワードのリスクとは何ですか？

侵害されたサイトがパスワードをどのように保存していたかを示します。平文は保護なし、解読が容易は MD5 や SHA1 などの弱いハッシュ化、解読が困難は bcrypt などの強いハッシュ化を意味します。不明はデータから判断できなかったことを意味します。

侵害データベースは無料ですか？

はい。登録なしで閲覧、検索、絞り込みができます。ご自身のツールに取り込みたい場合は、同じデータを無料 API から利用できます。

どのくらいの頻度で更新されますか？

新しい侵害が検証され読み込まれるたびに更新されます。ページ上部の「最終更新」の行が最新の追加を示し、各エントリには侵害日と追加日の両方が記載されています。

コミュニティによって、コミュニティのために構築されています。GitHub で完全にオープンソースです。
